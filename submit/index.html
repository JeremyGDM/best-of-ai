Submit a Tool

Submit an AI tool

Best of AI is a free, open source directory maintained on GitHub. If a useful AI tool is missing from the list, you can add it. Anyone can contribute — no special access required.

// why get listed

Best of AI is indexed by search engines and browsed by people looking for specific types of AI tools. The directory currently covers 1000+ tools across 100+ categories, and the full dataset is available as open data at /index.json, so other projects and directories pull from it too.

Getting listed puts a tool in front of users who are already searching by category, use case, or pricing model. Listings are free, permanent, and not ranked by payment — only by community-assessed quality.

// how to submit
easiest
// via github issue

Open the submission form on GitHub, fill in the fields below, and post the issue. Maintainers review it and add the tool to the repository. You only need a GitHub account.

required fields
name e.g. Midjourney
website e.g. https://midjourney.com
category pick from the list below
pricing Free / Freemium / Paid
description one sentence, under 100 chars
why include what makes it genuinely useful
Open submission form
for developers
// via pull request

Fork the repo, add a Markdown file to content/tools/, and open a PR. This path lets you set every field precisely and usually gets reviewed faster since the data is already formatted.

content/tools/toolname.md
---
name: Tool Name
slug: tool-name
website: https://example.com
category: image-generation
price: Freemium
description: One-sentence description of what it does.
tags:
  - image-generation
  - creative
  - ai-art
rank: 5
---
field notes
categorymust match a slug from data/categories.yaml
priceFree, Freemium, or Paid
rank1–10, default 5 if unsure
tags3–8 tags, lowercase, hyphenated
View the repository
// what happens after you submit
01
Your issue is posted

The issue goes into the submissions queue on GitHub. You can track it there and answer any follow-up questions from maintainers.

02
Maintainers review

Submissions are checked in batches, usually within a few days. Maintainers verify the tool is live, the category fits, and the description is accurate.

03
Tool is added to the directory

Accepted tools get a Markdown file in content/tools/ and appear on the site after the next deploy. The issue is closed with a link to the new listing.

// what gets accepted

There's no strict bar to clear, but a few things affect how quickly a submission gets merged. The tool should be publicly accessible — not invite-only or vaporware. The website should load. The description should say what the tool actually does rather than repeating marketing copy.

Duplicate entries, tools that appear to be AI-generated landing pages with no real product behind them, and submissions without enough information to verify the tool are the most common reasons for rejection. When in doubt, submit anyway — the issue will get a note if something's missing.

You can submit a tool you built yourself. Disclosing that in the issue is good practice and doesn't hurt the submission.

// common questions
Is there a fee to get listed?

No. Best of AI is a free, open source directory. Listing a tool costs nothing and there are no paid placements or promoted spots.

How long does review take?

Most submissions get reviewed within a few days. Maintainers work through the queue in batches. If yours has been open for more than a week without a response, add a comment to bump it.

Can I submit a tool I built myself?

Yes. Self-submissions are fine. Mentioning that you're the developer in the issue is appreciated but not required.

What if the tool already has a listing with wrong information?

Open an issue to flag the correction, or submit a PR directly to the tool's Markdown file in content/tools/. The filename matches the tool's slug.

What if no category fits my tool?

Pick the closest match and mention the gap in the issue. New categories get added when enough tools warrant one. If you're unsure, the maintainers will suggest the right fit.

Can I use the directory data in my own project?

Yes. The full index is available at /index.json and the raw Markdown files are in the public GitHub repository. No API key or account needed. The project is open source.
